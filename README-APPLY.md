# Seekho Digital – Projects Hub polish

This patch updates two existing files on the `platform-redesign` branch:

- `assets/js/projects.js`
- `assets/css/learning-tools.css`

## What changes
- Shows the project deliverables as a checklist for each of the 10 modules.
- Saves checklist ticks locally in the learner's browser.
- Shows an overall deliverable-check count.
- Reveals the guided steps for each project.
- Downloads a portfolio case-study starter template for each module.
- Repeats the honest practice-project disclosure so students do not misrepresent fictional work.

## Apply safely
1. Open the GitHub repository and switch to `platform-redesign` (do not edit `main`).
2. Replace `assets/js/projects.js` with the file in this ZIP.
3. Open `assets/css/learning-tools.css`, keep all existing content, and append the CSS addition from this ZIP (do not replace the whole stylesheet).
4. Commit the changes to `platform-redesign`.
5. Wait for GitHub Pages deployment to finish, then test `projects.html` on a phone.

This patch does not connect a database or sync learner progress across devices. Checklist progress remains local to the browser.
