# Seekho Digital Academy: Stage 1
Static site for GitHub Pages (branch: platform-redesign). Open index.html or serve the folder; all paths are relative.
- assets/css/style.css: design system (tokens, components)
- assets/js/site.js: shared header/footer, menu, module cards, tabs, sample question
- assets/data/site-data.js: nav links and module data (edit here)
- assets/images: logo and hero (local SVG). Icon sprite is inlined in site.js
Built: homepage, Our Learning, navigation. Placeholder pages (clearly marked "Being built"): about, practice, projects, interview, blog, updates, resources, workbook, community, faq, modules/module-01..10.
Not built: lessons, quizzes, progress, backend features (community, AI assistant).
Fonts: DM Sans/Manrope are used only if installed; system fonts otherwise (no external requests).
